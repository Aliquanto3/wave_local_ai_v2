# VCS

The version-control conventions this project follows.

## Setup

- Main branch: `main`
- Platform: GitHub

## Branches

- Format: `type/short-description`
- Types in use: `feat`, `fix`, `chore`, `docs`, `test`, `refactor`

## Commits

- Convention: Conventional Commits
- Format: `type(scope): description`
- Rules: imperative mood, lowercase, English only
