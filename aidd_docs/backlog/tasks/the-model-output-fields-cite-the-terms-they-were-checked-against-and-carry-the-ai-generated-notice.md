# Task: The model-output fields cite the terms they were checked against and carry the AI-generated notice

## Outcome

The licence text a reuser reads states that the model-output fields are redistributed as each model's licence and each provider's terms permit, as read on 2026-10-02 by the spike `aidd_docs/backlog/spikes/may-the-model-outputs-in-the-published-rows-be-redistributed-and-on-what-terms.md` (`resolved`), instead of an unverified declaration; and it carries the one condition those terms impose: model-generated content is marked as AI-generated, names the model and provider that produced it, and is not presented as human-written.

Current state (verified on `main` at `c68b23e`, 2026-10-03): `LICENSE-DATA` section 1.3 says the model-output fields are redistributed on the "author's declaration that redistributing it is permitted. That declaration is unverified against each model's licence and each provider's terms, and stays unverified until the spike" concludes; section 3 item 2 repeats it as one of two unverified assumptions; `aidd_docs/results/NOTICE.md` says the same ("unverified against each model's and provider's terms"). The committed rows' only model-output field is `predicted_label`.

## Scope

- Includes: `LICENSE-DATA` section 1.3 and section 3 item 2 rewritten to cite the spike and its read date, leaving the hand-written-items declaration (section 3 item 1) as the only unverified assumption; `aidd_docs/results/NOTICE.md` brought in line; the notice, worded as the spike's Follow-up gives it: "Fields holding model-generated content (`predicted_label` today; a subject's generated text and a judge's verdict or rationale when present) are AI-generated by the model and provider the row names, were not written by a human, and may contain errors."
- Excludes: licensing the model outputs under CC-BY 4.0 (the 1.3 carve-out stays a separate part, as the epic's Boundaries and the `done` licence story decided); the bundle epic's own Assumptions row, which the owner updates (Q111); the release archive's README, which `each-release-attaches-one-archive-that-needs-no-clone.md` writes and which carries the same notice once it ships open-ended output; any judge rationale field, whose story carries the notice when it first publishes one.

## Done When

- `LICENSE-DATA` 1.3 and 3 and `aidd_docs/results/NOTICE.md` no longer call the model-output redistribution unverified; each names the spike by path and the 2026-10-02 read date.
- The notice appears in both files, word for word the same.
- `uv run pytest tests/test_data_licence.py` passes; if a test there asserts the old wording, it is updated to the new one, not deleted.
