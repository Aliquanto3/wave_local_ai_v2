# Codebase Audit: code-quality (`src/wave_local_ai_v2/`, `scripts/`)

No correctness break today. The debt is cross-story drift: the three CLIs (runtime `__init__.py`, `quality_cli.py`, `judge_probe.py`) each re-implement the run preamble, the local generation loop, the local cost block, the failure taxonomy and the verdict block. Several copies have already started to diverge. That is the path by which two code paths could publish one metric two different ways.

- **Date**: 2026_09_22
- **Scope**: `src/wave_local_ai_v2/` (43 modules, 12,104 lines incl. scripts), `scripts/`. `read_model.py` audited as it stands in the working tree, with uncommitted in-flight changes from `dense-and-moe-side-by-side` in `_comparison_columns` / `comparison_view`.
- **Health**: good (no critical finding; see rubric)
- **Findings**: 0 critical, 7 warning, 10 minor

Health: `good` = no critical findings; `fair` = critical findings exist but are isolated and addressable; `poor` = systemic or widespread critical findings.

Correction to the brief: the "three verbatim `/completion` POST copies" no longer exists. Tech-debt row 2026-09-06 `judge_probe.py:548-588` was closed when `local_client.py` landed.
