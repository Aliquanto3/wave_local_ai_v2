# Codebase Audit: architecture (src/wave_local_ai_v2, frontend/src/api, scripts)

The single-writer row contract holds (every row goes through `results.append_row`), but the reproduction verdict, the gate's presence-only check and a 7-module import cycle through `row_contract` undermine the defensibility of published numbers on three machines.

- **Date**: 2026_09_22
- **Scope**: `src/wave_local_ai_v2/` (43 modules), `frontend/src/api/` + `frontend/src/views/*/types.ts`, `scripts/`, architecture docs in `aidd_docs/memory/`
- **Health**: fair
- **Findings**: 2 critical, 7 warning, 3 minor

Audited as-is on `feat/dense-moe-view` with uncommitted changes to `read_model.py` (comparison column key) and `frontend/src/views/comparison/` (in-flight dense-and-moe story). Finding 8 touches that in-flight code.

Evidence method: the import graph was built with an `ast` pass over module-level imports (fan-in, transitive closure, strongly connected components). The runtime module load was measured with `python -c "import wave_local_ai_v2.service; print(sys.modules)"`. The reference bundle was grouped with a one-off `json` pass over `aidd_docs/results/*-reference.jsonl`.

## Top actions

1. **Fix reference selection in the verdict before regenerating the bundle.** This resolves findings 1, 2 and 7. Pick one reference run explicitly, treat a null blocking field as not comparable, and load references through the floored reader. Settle the Methodology 8 vs blocking-set divergence (PRD decision) before the three-machine campaign. Hand-off: `aidd-dev:08-debug` for finding 1 (a test that reproduces the failure first), then `aidd-pm:04-spec` for the blocking-set decision.
2. **Make the read side provably independent of the write side.** This resolves findings 3, 4 and 10. Move the runtime CLI out of `__init__`, break the `row_contract` cycle by inverting vocabulary ownership, and add an import-boundary test. Hand-off: `aidd-dev:07-refactor` (architecture axis).
3. **Close the Python→TS contract gap and harden the absence reasons.** This resolves findings 5, 6 and 8. Generate the frontend fixtures from the Python views over the committed bundle, add `FIELD_INTRODUCED_IN`, and expose superseded runs in the comparison view. Hand-off: `aidd-dev:06-test` for the golden files, `aidd-dev:07-refactor` for the rest.
4. **Add one row-assembly seam for the three writers.** This resolves finding 9. Hand-off: `aidd-dev:07-refactor`, sized as a story.
